## About me

I’m a **Senior Technical Project Manager** with a background in full-stack development and software engineering team leadership. I work with stakeholders to define what needs to ship and with engineers to turn that scope into deliverables, sequence dependencies, and make decisions about implementation and release readiness.

My engineering background lets me stay involved when delivery depends on an API integration, a deployment issue, or a change to the application architecture. I also work on AI integrations and automation for existing products and workflows.
